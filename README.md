## Featured Projects

### [Manatee Call Detection](https://github.com/Matf021/manatee-call-detection)
- Developed Gaussian Hidden Markov Models for detecting and classifying marine mammal vocalizations
- Built an audio-processing pipeline with noise reduction, band-pass filtering, segmentation, and MFCC feature extraction
- Evaluated model performance using cross-validation, accuracy, precision, recall, and F1-score
- Integrated the detection pipeline into a Flask-based analysis application

### [AWS Voice Notes Organizer](https://github.com/Matf021/aws-voice-notes-organizer)
- Built a serverless application that transcribes, organizes, and analyses recorded voice notes
- Integrated AWS Transcribe and Amazon Comprehend for speech-to-text and natural-language processing
- Designed REST APIs with AWS Chalice for audio uploads, transcription tracking, and text analysis
- Implemented note categorization, sentiment analysis, key-phrase extraction, search, and favourites

### [Oracle Hospitality Management Project](https://github.com/Matf021/Oracle-hospitality-management-project)
- Designed a relational Oracle database for hotel reservations, room assignments, guest stays, folios, payments, and restaurant charges
- Developed modular PL/SQL packages to automate reservation, check-in, billing, payment, and checkout workflows
- Implemented business-rule validation for room availability, occupancy limits, overlapping reservations, duplicate charges, and unpaid balances
- Created automated PL/SQL test suites covering successful workflows and expected error conditions
- Containerized the Oracle Database development environment using Docker

### [NLP Sentiment Analysis](https://github.com/Matf021/nlp-sentiment-analysis)
- Compared lexicon-based approaches, including VADER and TextBlob, with supervised machine-learning models
- Developed TF-IDF pipelines using Logistic Regression and Linear SVM for sentiment classification
- Evaluated models using accuracy, precision, recall, and F1-score
- Achieved approximately 86% classification accuracy with the strongest machine-learning models
